## 回归测试

在提供官方 EGNet VGG16/ResNet50 权重和参考代码后执行完整 pytest：**12 passed in 12.91s**。不提供外部文件时，10 项测试可离线执行，2 项官方权重/参考代码对比测试跳过。

覆盖内容：不同节点数的批量反投影及梯度、均值池化及梯度、batch 1/2 所有训练参数的梯度和实际更新、空/满掩码、VGG19 层形状及本地权重往返、编码器不兼容拒绝、图边权与稀疏化、逐级融合真实连接来源的干预测试、旧解码器版本拒绝，以及两种 EGNet 官方权重的逐元素特征对比。ResNet 对比包含 batch=1 的 256×256 输入和 batch=2 的 255×257 奇数尺寸输入，覆盖 ceil_mode 边界行为；还验证缺少通道投影权重时明确拒绝加载。

## 完整 CLI 自检

```bash
python smoke_test.py --work-dir runs/sequential256 --size 256
```

使用 3 张合成图（训练 2 张、验证 1 张）、随机 VGG19（seed=0）、实际 SNIC/PyG，目标区域数 50/100，K=32。第一轮 batch=2，续训第二轮 batch=1：

| 输入 | 第一轮训练损失 | 续训后训练损失 | 状态 | 单次墙钟时间 |
|---|---:|---:|---|---:|
| 256×256 | 13.011775 | 12.729563 | passed | 48.01 s |

生成 latest.pt、best.pt、history.json 和 predictions.json；预测 PNG 为灰度，尺寸为原始 86×66。SNIC 在这些样本上实际生成 64/121 个区域，目标数量与实际数量须区分。

这些损失仅说明流程完成且数值有限，**不能作为任何数据集性能指标**。时间包括子进程启动、预处理、训练/续训和预测，不是 FPS 或完整数据集训练时间；同一机器上的其他进程可能影响时间。

## 三种实际预训练权重路径

| 编码器 | 验证内容 | 单步五头总损失 | 输出检查 |
|---|---|---:|---|
| torchvision ImageNet VGG19 | 256×256、2 张合成训练图、batch=2 Adam 更新 | 12.989072 | batch=2 预测，灰度 PNG 恢复为 80×56、83×61 |
| 官方 EGNet VGG16+Conv6 | 256×256、2 张合成训练图、batch=2 Adam 更新 | 13.032805 | 独立无标签图预测，灰度 PNG 恢复为 86×66 |
| 官方 EGNet ResNet50+ConvertLayer | 256×256、batch=2 训练、batch=1 续训、独立验证与预测 | 首轮 13.076864；续训 12.652222 | 完整自检通过，灰度 PNG 恢复为 86×66 |

三种编码器均通过实际预处理、图网络训练和 checkpoint 加载/预测，均未在此次验证中进行 EORSSD 编码器微调。EGNet 官方模型的下载来源、文件摘要、参考实现逐元素一致性验证见 [EGNet 核验记录](EGNET_CHECK.md)。

ResNet 完整自检单次墙钟时间为 39.44 s，包含进程启动及预处理；同机还有其他测试运行，不能据此进行速度排名。新增编码器参数后，默认随机 VGG19 的 64×64 自检也重新通过（25.60 s），确认原离线入口仍可运行。详细 ResNet 结构与命令见 [ResNet 核验记录](EGNET_RESNET_CHECK.md)。

## 规模与边界

当前默认双尺度解码器有 **547,133** 个训练参数，减少来自后两级拼接前一层融合特征的通道调整。此数不含冻结编码器、图预处理及缓存资源，不能直接当作论文完整系统的复杂度。未测 FLOPs、峰值内存或规范化 FPS。

没有运行全量 EORSSD、跨数据集实验或 CUDA 测试，也没有复现论文精度。已找到并验证可用的 EGNet 显著性预训练编码器，但不能确认其就是作者原实验权重。文稿 VGG19/EORSSD 微调与 EGNet VGG16 或 ResNet50/DUTS 训练之间的差异仍需核实。
